# ATPlayer App Review demo audio

This package contains one original audio file for reviewing ATPlayer 1.0.2:

- Morning-Light.wav — title metadata: «Утренний свет»; artist: ATPlayer Demo.
- Format: uncompressed PCM WAV, mono, 44,100 Hz, 16-bit.
- Duration: 120 seconds.

## Review steps

1. Save this ZIP to Files on the review device and extract it.
2. Open ATPlayer. In the default My Music playlist, tap «Добавить музыку» (Add Music) or the plus button inside the playlist.
3. Select Morning-Light.wav from the extracted folder and wait for the track to appear.
4. Tap the track to start playback. The large central button pauses and resumes playback; drag the circular progress ring to seek.
5. Leave the app or lock the device to review background playback and system playback controls. Live Activities depend on device support and system settings.
6. The sliders button at the top right opens settings; «Эквалайзер» opens the 10-band equalizer and preamp.

Keep the extracted file in its location while reviewing. ATPlayer stores a reference to the selected file rather than a separate copy of the audio. No account or network connection is needed to play this locally available demo. The demo audio is supplied for review only and is not bundled with the production app.
