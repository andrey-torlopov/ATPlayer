# ATPlayer — App Store creative asset

Готовый файл для **Product Page Header** и **Search Results**: [`header-universal.png`](header-universal.png).

- Размер: **5244 × 2950 px**, PNG, непрозрачный RGB, профиль sRGB IEC61966-2.1.
- Одна версия для русского и английского языков: видимого текста нет.
- Композиция: центральный знак воспроизведения, радиальная звуковая волна и спокойный тёмный фон в палитре ATPlayer. Значимые элементы расположены по центру; боковой ритм — декоративный.
- Это самостоятельная иллюстрация бренда. Она не изображает устройство, экран приложения или вымышленные функции и не заменяет настоящие скриншоты.

Параметры соответствуют универсальному PNG-формату для обоих размещений из [Apple Creative Assets Specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications/), проверенных 1 ноября 2026 года. Основной агент проверил итоговые русские Product Page и Search Results через Device Preview в App Store Connect: visual PASS.

## Размещения в App Store Connect

- Русский Header: файл загружен, показано **1 of 1**.
- Русский Search Results: включено **Use Header**, показано **1 of 1**.
- Английский Header: **Using Russian header asset**.
- Английский Search Results: **Using Russian search results asset**.

Это подтверждённые наблюдения основного агента в текущем чате. Они фиксируют сохранённые материалы карточки, но не означают отправку на App Review или публичный выпуск. Подробности записаны в [`verification.json`](verification.json).

## Исходники и воспроизведение

[`generate_header.swift`](generate_header.swift) создаёт [`header-universal.svg`](header-universal.svg) и PNG из одной геометрии. SVG — редактируемый векторный исходник; PNG рисуется штатным CoreGraphics в непрозрачный RGB-контекст. Сторонние библиотеки и загрузки не используются.

```sh
swift -module-cache-path /private/tmp/atplayer-creative-module-cache Artifacts/AppStore-2026-11-01/creative-assets/generate_header.swift
```

Команда запускается из корня проекта и перезаписывает только два созданных файла в этой папке. Это запуск автономного графического скрипта, а не сборка приложения ATPlayer.

Основа стиля: палитра и принцип радиального мотива из [`docs/tools/generate_artwork.py`](../../../docs/tools/generate_artwork.py) и [`docs/assets/banner-en.svg`](../../../docs/assets/banner-en.svg). Для магазина создана новая композиция без текста и иллюстративного плейлиста.

## Проверка

Фактический PNG просмотрен визуально. Проверены размер, тип RGB без alpha, отсутствие PNG transparency-chunk, корректность CRC всех PNG-chunks, встроенный sRGB-профиль и SHA-256. SVG проверен XML-парсером: нет видимого текста, встроенных растровых картинок, шрифтов и внешних ресурсов. Центральный основной мотив помещается в номинальные центральные кропы 21:9 и 3:2; расчёты и точные границы записаны в [`verification.json`](verification.json).
