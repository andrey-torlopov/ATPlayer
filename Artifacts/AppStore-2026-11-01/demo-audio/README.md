# Демо-аудио для скриншотов ATPlayer

Четыре оригинальных синтетических фоновых композиции для импорта через «Файлы» и съёмки настоящего интерфейса ATPlayer:

| Файл | Длительность |
|---|---|
| Утренний свет.wav | 2:00 |
| Тихий берег.wav | 2:08 |
| Между облаками.wav | 2:16 |
| Дорога домой.wav | 2:24 |

Аудио создано 1 ноября 2026 года скриптом `generate_demo_audio.py` только из синусоидальных осцилляторов. Записи, семплы, сторонние произведения, чужие обложки и узнаваемые мелодии не использовались. Это спокойные статические гармонии с плавным изменением громкости. В метаданных указан исполнитель `ATPlayer Demo`; названия также сохранены в именах файлов.

Формат: WAV, PCM, mono, 44 100 Гц, 16 бит. Мастер-уровень ограничен значением 0,18 от полной шкалы; фактический пик проверен отдельно и не превышает 0,2. Эти файлы предназначены для демонстрационной медиатеки и не должны включаться в production bundle приложения.

## Воспроизведение генерации

```sh
python3 generate_demo_audio.py
```

Скрипт использует только стандартную библиотеку Python. Он перезаписывает четыре WAV в этой папке и `verification.json`. Проверяет RIFF/WAV-заголовки, формат PCM, количество кадров и пиковую амплитуду. Для каждого файла сохраняет SHA-256.

Формулы проверки: длительность = число кадров / частота дискретизации; относительный пик = максимальный модуль PCM-сэмпла / 32768. Числители, знаменатели и результаты записаны в `verification.json` и выводятся при генерации.
