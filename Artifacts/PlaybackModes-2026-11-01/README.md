# ATPlayer: режимы воспроизведения

Дата: 1 ноября 2026 года. Изменения реализованы локально; сборка в App Store не отправлялась, версии и теги не менялись, commit/push не выполнялись.

## Реализованное поведение

- Одна кнопка под настройками переключает повтор плейлиста → shuffle → повтор одного трека → обычное воспроизведение. Значок меняется вместе с режимом: `repeat`, `shuffle`, `repeat.1`, `arrow.right`. Одновременно активен только один режим.
- Повтор плейлиста замыкает его очередь в сохранённом порядке.
- Shuffle перемешивает текущий плейлист. Выбранный трек остаётся первым в новом проходе; остальные играют без повторов. «Назад» идёт по той же очереди. Сохранённый порядок треков не меняется.
- «Один трек» трактуется как повтор выбранного трека по кругу. Ручные «Назад» и «Далее» переключают треки внутри его плейлиста; автоматическое завершение запускает текущий трек заново.
- Обычное воспроизведение сохраняет прежний последовательный обход всех плейлистов. В режиме shuffle плеер останавливается после одного прохода текущего плейлиста.
- Выбранный режим сохраняется между запусками. Сама перемешанная очередь не сохраняется; при новом выборе трека формируется новый проход.
- Поиск доступного файла ограничен одним конечным списком кандидатов, даже при повторе. Если доступных файлов нет, воспроизведение останавливается с сообщением. При автоматическом повторе одного недоступного трека другой трек не подставляется.

Новая очередь фиксируется вместе с выбранным треком. Отменённая загрузка не подменяет очередь ещё играющего файла. Изменение режима во время ожидания iCloud заставляет пересчитать исходное действие по актуальным правилам. Исходный файл и его security scope остаются под существующим управлением аудиосервиса/view model.

## Изменённые файлы

- `SRC/ATPlayer/ATPlayer/Models/PlaybackQueue.swift` — режимы и стабильная конечная очередь.
- `SRC/ATPlayer/ATPlayer/ViewModels/ATPlayerViewModel.swift` — выбор области очереди, переходы, завершение трека, сохранение настроек и защита асинхронных переключений.
- `SRC/ATPlayer/ATPlayer/Views/Components/V1/PlayerPanelV1.swift` — удалены два отдельных переключателя под основным управлением.
- `SRC/ATPlayer/ATPlayer/Views/Components/V1/ATPlayerRootViewV1.swift` — одна кнопка режима под настройками, меняющийся значок и VoiceOver.
- `docs/en/features.md`, `docs/ru/features.md`, `docs/en/releases.md`, `docs/ru/releases.md` — правила новых режимов с явной отметкой, что их нет в ранее отправленной сборке 1.0.2 (1).

V0, схема SwiftData, аудиодвижок, signing, entitlements и настройки публикации не менялись.

## Проверка единой кнопки

Проверен вариант с одной кнопкой под настройками и четырьмя взаимоисключающими режимами. Старый скриншот двух кнопок сохранён только как исторический артефакт.

Локальная сборка приложения и расширения выполнена командой:

```sh
xcodebuild -project SRC/ATPlayer/ATPlayer.xcodeproj -scheme ATPlayer -configuration Debug -destination 'generic/platform=iOS Simulator' -derivedDataPath /private/tmp/ATPlayer-PlaybackModes-DerivedData CODE_SIGNING_ALLOWED=NO build
```

Результат: `BUILD SUCCEEDED`, предупреждений компилятора нет. Лог: [app-build.log](app-build.log).

Проверки очереди и интеграции запускаются отдельным [скриптом](run_playback_regressions.py). Production-исходники компилируются без подмен сервисов. Интеграция работает в отдельном simulator bundle и с независимой базой в памяти. Проверяются переходы на границах плейлистов, оба вида повтора, shuffle, ручные команды, недоступные файлы, возобновление после ошибки и отмена отложенного перехода паузой.

Результат, вычисленный Python из актуальных JSON-отчётов:

```text
Passed / total = (14 + 13) / (14 + 13) = 27 / 27
Source hashes verified: 10; compiler warnings: 0
```

Отчёты: [очередь](queue-results.json), [интеграция](integration-results.json), [команды и SHA-256](regression-run.json), [сводная проверка](verification.json).

Через интерфейс Debug-сборки проверены одна кнопка под настройками, полный цикл из четырёх состояний, отсутствие прежних переключателей под транспортом, портретная и компактная альбомная компоновки. [Скриншот единой кнопки](player-single-mode.jpg). Интеграционные проверки подтвердили сохранение текущего трека и позиции при переключении режимов во время воспроизведения и паузы, сохранение режима и перенос настроек с предыдущего варианта.

Выполнены самопроверка изменений, `git diff --check` и `python3 docs/tools/validate_docs.py`: 15 Markdown-файлов, 94 локальные ссылки и 4 SVG проверены успешно.

Ограничения: интеграционные тесты вызывают завершение через production `seek(to: duration)`; естественный callback конца файла отдельно не проверялся в этом прогоне. Реальное ожидание iCloud и его отмена проверены по коду, но не воспроизведены с облачным провайдером. Физическое устройство, фон, прерывания и Bluetooth требуют отдельного ручного прохода.
