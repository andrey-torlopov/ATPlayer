# ATPlayer documentation

*[Русский](../ru/index.md)*

ATPlayer plays your own audio files on iPhone and iPad. The interface and documentation are available in Russian and English.

- [Quick start](quick-start.md): add files and start listening.
- [Features](features.md): playlists, playback order, equalizer, radio effect, Live Activities, and limits.
- [Data and privacy](data-and-privacy.md): original files, local storage, iCloud, and export.
- [Development and architecture](development.md): open the Xcode project and find the relevant code.
- [Release status and verification](releases.md): what is prepared and what is not yet published.
- [Support](../../SUPPORT.md): troubleshooting and contact.
- [Privacy policy](../../PRIVACY.md).

Version **1.5.0** adds an optional radio effect, off by default, with separate maximum and background controls. See [release status](releases.md) for verified preparation and submission milestones.
