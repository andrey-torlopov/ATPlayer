# Noise Demo

Отдельное iOS/iPadOS-приложение для экспериментов с радиопомехами и поглощением музыки. Основной шум — реальная запись `12-Uniden-radio-static-bursts.wav`; процедурный синтез доступен отдельно. Минимальная версия — iOS/iPadOS 18. SwiftUI-компоновка адаптируется к iPhone и iPad. Автоматического запуска звука нет.

Откройте `NoiseDemo.xcodeproj`, выберите схему **NoiseDemo** и симулятор iPhone/iPad, затем Run. Для физического устройства настроена Automatic signing с командой `79798GRSHW`, как у ATPlayer; при другом Apple-аккаунте выберите свою команду. Подпись и запуск на устройстве этой проверкой не подтверждаются. Проект зависит только от продуктов RadioNoiseKit и RadioNoiseAssets локального пакета `../ATPlayer/LocalPackages/RadioNoiseKit`; зависимости от ATPlayerKit нет. Запись12 входит в ресурсный bundle пакета. Другие WAV-референсы и музыка выбираются пользователем.

```sh
xcodebuild -project SRC/NoiseDemo/NoiseDemo.xcodeproj \
  -scheme NoiseDemo -configuration Debug -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/NoiseDemoBuild CODE_SIGNING_ALLOWED=NO build
xcrun simctl install booted /tmp/NoiseDemoBuild/Build/Products/Debug-iphonesimulator/NoiseDemo.app
xcrun simctl launch booted dev.torlopov.noisedemo
```

Если запущено несколько симуляторов, замените `booted` на UDID выбранного устройства. Нужен Xcode с поддержкой Swift tools version из `RadioNoiseKit/Package.swift`. Демо не запрашивает микрофон.

## Работа с демо

- **Шум** — выбранная основа радиопомех соло. По умолчанию **Запись 12**: реальные фрагменты исходного WAV без изменения высоты тона, с выровненной громкостью, случайной последовательностью и плавными стыками. Seed меняет последовательность.
- **Синтез** — отдельный экспериментальный режим. Только в нём видны характер, компоненты и пресеты **07**, **08**, смешанный, звон, затухающие серии и синтетический12. Пресеты сохраняют громкость и seed; компоненты синтеза не влияют на записанный шум.
- **Референс** — выбранный WAV. **Открыть WAV…** использует «Файлы»; громкость и повтор настраиваются отдельно. Для сравнения соло-шума с исходной записью согласуйте громкости вручную.
- **Музыка + шум** — импортируйте музыку кнопкой **Открыть музыку…**, выберите этот источник и нажмите **Старт**. Поддерживаются локальные форматы AVAudioFile, включая WAV/MP3, mono/stereo. Файл проигрывается целиком один раз. По завершении звук останавливается.
- **Радио эффект** задаёт максимальную глубину событий по шкале0–10. Новый максимум10 соответствует прежнему7: музыка остаётся на42.5%, шум достигает67.5% исходного RMS музыки. Новые1/2 оставляют музыку на89.5/83% и добавляют шум с целевым RMS14/24%. Ноль пропускает чистую музыку. Это коэффициенты амплитуды и отношения RMS, а не проценты воспринимаемой громкости.
- **Фон радио эффекта** задаёт постоянный уровень шума между событиями по той же шкале. Он не может быть выше основного уровня: повышение фона выше эффекта поднимает эффект, снижение эффекта ниже фона снижает фон. Значения по умолчанию —10/7: шум меняется от51.75% до67.5% исходного RMS музыки. При7/7 целевой уровень шума постоянный51.75%; приглушение музыки во время событий сохраняется. Фон0 оставляет только всплески; эффект0 выключает весь шум. Повышение эффекта с0 сохраняет явно выбранный нулевой фон.
- Событие входит плавно, держит глубину случайные1–6с и плавно возвращается к выбранному фону. Первый интервал —3–6с, промежутки между последующими событиями —8–18с. Глубина не меняет длительность и частоту событий. Положительный фон остаётся в тихих местах и цифровых паузах файла; новые случайные события в них не запускаются. Для фона сохраняется последний измеренный RMS музыки. До первого слышимого сигнала используется начальная опора0.02. При фоне0 тишина подавляет шум; явная остановка аудиодвижка выключает любой фон.
- **Громкость смеси** — отдельный уровень прослушивания, по умолчанию −12 дБ. **Громкость шума соло** на смесь не влияет. Выбор **Запись 12 / Синтез** действует и в смеси. В синтезе **Только** оставляет один компонент; **По умолчанию** сбрасывает его параметры и громкость, сохраняя seed, музыку и перекрытие.
- Seed — десятичный UInt64. Одинаковые seed, параметры и sample rate повторяют шум при новом запуске. Изменённое поле применяется при следующем старте; кубик перезапускает активный генератор или смесь с новым seed.
- **Старт / Стоп**, **С начала** и переключение источников используют только один аудиодвижок/плеер одновременно. Переключение во время воспроизведения запускает новый источник с начала. Переключение основы шума перезапускает активный шум или смесь, но не прерывает внешний WAV-референс. В остановленном состоянии параметры и выбор основы не запускают звук. Открытие файла не запускает его автоматически. Начатую подготовку музыки можно отменить.
- Импортированные файлы не копируются: security-scoped доступ удерживается до замены или завершения приложения. Для файлов из облака может потребоваться предварительно загрузить их в «Файлах».
- Прерывание, смена маршрута и уход приложения в фон останавливают звук и деактивируют аудиосессию. Автоматического возобновления нет.

## Аудиотракт и проверка

Соло использует `AVAudioSourceNode`. Для музыки `AVAudioPlayerNode` читает файл, промежуточный mixer приводит формат к stereo/output sample rate, затем внутренний `NoiseMixAudioUnit` применяет выбранный источник шума и общий `RadioInterference` из пакета. Запись декодируется, выравнивается по громкости и преобразуется к частоте выхода до запуска аудиопотока. Из подготовленной версии удаляются почти неслышные промежутки, остальные фрагменты соединяются плавно. `RadioSamplePlayer` владеет копией PCM. Ошибка загрузки записи останавливает запуск с сообщением; автоматической подмены синтезом нет. Соло и смесь запрашивают `loadReference12(sampleRate:balanced:true)` и используют постоянный RMS подготовленной записи. Исходный PCM доступен через загрузчик без `balanced`, а внешний исходный WAV можно открыть в режиме «Референс». Экспериментальный синтез использует прежнюю динамическую нормализацию.

Модель событий, gain law и нормализация записи совпадают с ATPlayer; его limiter в демо не включается. У смеси есть финальное ограничение амплитуды ±1; слушать рекомендуется с запасом monitor gain. На нуле эффект пропускает конечные сэмплы без изменений до общего monitor gain.

Состояние C++ и указатели живут в стабильном владельце, в том числе если host получает render block до `allocateRenderResources`. MainActor — единственный writer параметров генератора; основной уровень и фон передаются одним lock-free `Atomic<UInt32>` и читаются согласованной парой один раз на блок. Аудиопоток владеет event/RMS-состоянием; в render callback нет файловых операций, выделений памяти и блокировок. Источник RMS измеряется до приглушения и фиксируется на время события. В конце файла generation guard не позволяет старому callback остановить новый запуск.

В схеме добавлен `NoiseDemoTests`. Тесты запускают реальный `AVAudioEngine` с этим Audio Unit в offline mode на iOS Simulator: противофазный тон отделяет музыку через `(L − R) / 2` от mono-шума через `(L + R) / 2`. Проверяются точный чистый проход на0, приглушение до0.425, события при10/7, наличие фона при1/1, ровная громкость шума при7/7, отсутствие фона при10/0, сохранение фона в немом вступлении и тихом фрагменте, плавное выключение фона между событиями, повторение seed, независимость записи от выключенных компонентов синтеза и тишина при выключенном синтезе. Соло-граф сравнивается посэмплово с PCM подготовленной записи через sampler; отдельно проверяется доступность исходного PCM. Также проверяются чтение mono WAV44.1kHz и тишина после окончания декодированного сигнала при фоне0, передача ошибки ресурса без подмены источника, согласование ползунков и отсутствие автозапуска настроек. Это проверка фактического render path, а не только `engine.isRunning`.

```sh
xcodebuild -project SRC/NoiseDemo/NoiseDemo.xcodeproj -scheme NoiseDemo \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  -derivedDataPath /tmp/NoiseDemoBuild CODE_SIGNING_ALLOWED=NO test
```

Результаты текущей итерации сохраняются в `../../Artifacts/Radio-1.4.0/Reference12Sample/demo/`. Демо не меняет библиотеку или настройки ATPlayer. Художественный результат поглощения требует прослушивания.
