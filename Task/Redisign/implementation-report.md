## Интерфейс

Референсы: `1.jpg`, `2.jpg`, `3.jpg`, `4.png` из этой папки. Изображения используются как направление дизайна; в приложение не копируются.

- Нейтральная поверхность, мягкие светлые и тёмные тени, графитовые кнопки с внутренним контуром, приглушённый зелёный акцент.
- Круг с прошедшим и общим временем; отдельное кольцо прогресса с маркером. Перемотка жестом по кольцу, предварительный просмотр позиции до отпускания; VoiceOver изменяет позицию шагами по пять секунд.
- Радиальный спектр из 72 столбиков. Данные берутся из аудио, случайные значения удалены. На паузе столбики возвращаются к базовому размеру; Reduce Motion отключает движение спектра.
- Название трека с резервным именем файла, формат файла и время. Обложки, альбомы и искусственные сведения об исполнителе в V1 не показываются.
- Плейлисты с явным импортом файлов/папки, раскрытием секций, переименованием и подтверждением удаления. Действия доступны без долгого нажатия.
- Статус импорта и отмена. Сообщения об ошибках можно закрыть.
- Светлая/тёмная тема, расположение в две колонки на широком экране, прокрутка на небольшом экране, подписи для VoiceOver.
- Для низкого горизонтального экрана используется компактный круг и транспорт. Минимальная ширина двух колонок учитывает узкие окна; при accessibility-размере текста остаётся одна колонка.
- Настройки и десятиполосный эквалайзер выполнены в том же стиле. Убрана принудительная смена ориентации при открытии эквалайзера V1.

## Версии компонентов

Исходники находятся в `SRC/ATPlayer/ATPlayer/Views/` относительно корня проекта.

| Путь | Назначение |
| --- | --- |
| `PlayerDesignVersion.swift` | Единая точка выбора версии; `current = .v1` |
| `Components/V0/` | Исходный интерфейс с суффиксом V0 |
| `Components/V1/PlayerThemeV1.swift` | Тема, поверхности и стили кнопок |
| `Components/V1/ATPlayerRootViewV1.swift` | Компоновка, импорт, ошибки и навигация |
| `Components/V1/PlayerPanelV1.swift` | Название и транспорт |
| `Components/V1/RadialPlayerV1.swift` | Время, прогресс, жест и радиальный спектр |
| `Components/V1/PlaylistViewV1.swift` | Плейлисты и строки треков |
| `Components/V1/SettingsViewV1.swift` | Настройки и экспорт |
| `Components/V1/EqualizerSettingsViewV1.swift` | Предусиление и частотные регуляторы |

Для сравнения интерфейсов достаточно заменить `PlayerDesignVersion.current` на `.v0`. Обе версии используют исправленные общие сервисы и модель. Оформление V0 сохранено; его визуализатор дополнен адаптером из 72 входных значений в исходные 24 столбика, чтобы не переполнять строку.

Xcode использует синхронизированную с файловой системой группу приложения: новые Swift-файлы подхватываются без изменения `project.pbxproj`. Подписи, capabilities, bundle ID и deployment target не менялись.

## Исправления по аудиту

| Дефект исходного кода | Изменение |
| --- | --- |
| Callback окончания мог сработать до фактического окончания звука | Используется `.dataPlayedBack`; поколение расписания отбрасывает старые callbacks после stop/seek |
| Прогресс зависел от настенных часов | Используется render/sample time аудиоплеера |
| После ошибки загрузки оставались старые файл, duration и playback state | Загрузка начинается с полного сброса; ошибка запуска аудиовыхода возвращается в UI |
| Stop сохранял файл и duration | Stop выгружает файл; pause сохраняет возможность продолжения; EOF сохраняет конечную позицию для повторного запуска |
| Очень длинный файл мог переполнить UInt32 frame count | Планирование выполняется последовательными сегментами |
| Визуализатор показывал случайные данные | Реальный FFT, усреднение мощности каналов, копирование PCM до возврата tap, один фоновый расчёт за раз; устаревшие результаты не публикуются |
| Не было корректной обработки аудиопрерываний и отключения наушников | Пауза при потере маршрута, обработка interruption/configuration/media reset; ручной запуск может повторно активировать сессию даже без уведомления окончания прерывания |
| EQ доверял сохранённому массиву и значениям | Число полос, конечность и диапазон значений нормализуются |
| Security scope старого файла освобождался до остановки аудио; новый мог утечь при ошибке | Остановка предшествует освобождению; доступ передаётся активному файлу только после успешной загрузки |
| Previous при проблемном файле переключался вперёд | Направление обхода сохраняется; недоступные кандидаты пропускаются в нужную сторону |
| Старый запрос iCloud/окончание старого трека могли перебить новый выбор | Токены запросов, отмена ожидания и защита автоматического перехода |
| Удаление активного плейлиста/трека оставляло selection и доступ к файлу | После успешного сохранения очищаются playback, selection, artwork, scope; удалённый последний section ID очищается |
| Сохранение/перенумерация удалений выполнялись раздельно | Одно сохранение операции; rollback при ошибке |
| Stale bookmarks просто отвергались | Bookmark обновляется; для импортированной папки сохраняется её grant рядом с bookmark файла |
| Bookmark потомка папки не сохранял grant родительской папки | Обратно совместимый envelope внутри существующего атрибута Data; схема SwiftData не меняется, старые raw bookmarks поддержаны |
| iCloud не принимал `.downloaded`, статус мог кэшироваться, отмена игнорировалась | Приняты `.current`/`.downloaded`, кэш статуса сбрасывается, polling учитывает отмену и устаревший запрос |
| Сканирование папки блокировало обработку отмены до завершения обхода | Асинхронный обход уступает MainActor на каждой итерации; отдельный медленный вызов файлового провайдера всё ещё может задержать итерацию |
| Одноимённые плейлисты перезаписывались при JSON export | Коллизии разрешаются уникальными ключами с суффиксом с учётом уже занятых имён |
| NaN/infinity duration могли попасть в Int и вызвать падение | Проверка конечности/диапазона перед форматированием |
| Название принудительно переводилось в uppercase, отсутствующий автор становился Unknown Artist | Естественный регистр, filename fallback; искусственный автор не показывается |
| URL открытия мог потеряться до создания ViewModel | URL сохраняется до инициализации модели и затем обрабатывается |

Дополнительно: отменённый жест перемотки автоматически сбрасывает preview через `GestureState`; обновления спектра не заставляют транспорт сортировать медиатеку на каждом кадре. Экспорт V1 передаёт Data непосредственно `FileDocument`, без промежуточного временного файла.

Во время полной проверки исправлены неверное имя SwiftUI environment key (`colorSchemeContrast`), предупреждение Swift об `NSFastEnumeration` в async-контексте (используется `nextObject()` с уступкой MainActor), и компоновка landscape iPhone: безопасная ширина была меньше исходного порога двух колонок, из-за чего транспорт уходил вниз за кругом.

- Независимый review VM/storage/model и аудиосервиса. Выявленные замечания про отмену сканирования и interruption latch устранены.

## Полная сборка и проверки Simulator

Пользователь отдельно разрешил сборку и проверку Simulator. Выполнена команда:

```sh
xcodebuild -project SRC/ATPlayer/ATPlayer.xcodeproj \
  -scheme ATPlayer -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /private/tmp/ATPlayer-Redisign-DerivedData \
  CODE_SIGNING_ALLOWED=NO build
```

Результат: `BUILD SUCCEEDED`, предупреждений в итоговом логе нет. Компилируются обе архитектуры Simulator и встроенное расширение. Лог: [Verification/build.log](Verification/build.log).

Отдельное временное UIKit-приложение скомпилировано вместе с настоящими production-файлами AudioPlaybackService, VM, storage, model и Activity dependencies с теми же флагами actor isolation/concurrency. Оно выполняет проверки настоящего Swift-кода в Simulator, используя inMemory SwiftData и созданные синтетические аудиофайлы.

Python подсчитал сохранённый JSON:

```text
audio: passed=33; total=33; successful / all = 33 / 33
logic: passed=56; total=56; successful / all = 56 / 56
total: passed=89; total=89; successful / all = 89 / 89
```

Проверены EOF после проигрывания и однократный callback; restart после EOF; seek/pause/resume; очистка состояния при stop/ошибке/пустом файле; EQ sanitize/restore; реальный спектр, тишина и противофазное stereo; mono/stereo с различными sample rates; обработчики interruption/route через внедрённые уведомления; SwiftData cascade/order; удаление активного трека/плейлиста; Previous/Next через missing/empty файлы; экспорт одинаковых имён; конечность duration; metadata fallback; legacy/envelope bookmarks и исправление пути; рекурсивный импорт и отмена.

Результаты первого этапа: [JSON](Verification/regression-results.json), [runtime log](Verification/runtime-final.log). Исходники проверок: [RegressionHarness.swift](Verification/RegressionHarness.swift), [LogicRegression.swift](Verification/LogicRegression.swift). Исправлен только тест: проверяется ограниченное по времени затухание, после чего итоговый прогон прошёл. Исходный лог сохранён в [runtime-initial.log](Verification/runtime-initial.log).

## Остаточный риск

Не проверены физические Bluetooth/AirPlay, реальные звонки, аппаратный media reset и realtime-профилирование. Внедрённые уведомления проверяют обработчики, но не аппаратный стек. Настоящий iCloud, grants сторонних Files-провайдеров, принудительный сбой SwiftData save, полный VoiceOver-аудит и матрица произвольных размеров окон iPad остаются непроверенными. Сканирование уступает MainActor между файлами, но отдельный медленный вызов провайдера и сортировка всё ещё могут задержать интерфейс.

Таймер отражает render time: на Bluetooth/AirPlay он может опережать слышимый звук на задержку вывода. Переход на следующий трек ждёт `.dataPlayedBack`. Низкие полосы спектра могут разделять один FFT bin из-за частотного разрешения преобразования; это визуализатор, а не измерительный прибор. Характеристики realtime и нагрузка на физическом устройстве не измерены.

Live Activities в исходной VM были закомментированы; расширение также содержит шаблонные виджеты/intent-заготовки. Их активация и отдельный редизайн не выполнялись. Исправления в этом отчёте относятся к основному приложению и активному пути воспроизведения.

В рабочем дереве до начала работы уже были удаления конфигурационных/документационных файлов и незарегистрированный Xcode-проект. Эти сторонние изменения не восстанавливались и не включались в текущую работу. Коммиты и публикация не выполнялись.
