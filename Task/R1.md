# R1: LiveActivity для ATPlayer

## Цель

Добавить Live Activity (Lock Screen + Dynamic Island), отображающую:
- Название трека (artist - title)
- Текущее время воспроизведения / общая длительность
- Кнопки управления: предыдущий, пауза/воспроизведение, следующий

## Анализ текущего состояния

### Проект
- **Тип:** Xcode project (не SPM)
- **Bundle ID:** `torlopov.app.one`
- **Deployment target:** iOS 26.2 (ActivityKit доступен с iOS 16.1)
- **Background modes:** `audio` - уже включён

### Ключевые компоненты для интеграции

| Компонент | Файл | Роль |
|---|---|---|
| `AudioPlaybackService` | `Services/AudioPlaybackService.swift` | Хранит `isPlaying`, `currentTime`, `duration` |
| `ATPlayerViewModel` | `ViewModels/ATPlayerViewModel.swift` | Управляет `play()`, `pause()`, `playNext()`, `playPrevious()`, `togglePlayback()`. Хранит `nowPlayingTitle`, `nowPlayingArtwork` |
| `TrackItem` | `Models/TrackItem.swift` | Модель трека: `title`, `artist`, `duration`, `artwork`, `displayTitle` |

### Что уже есть
- `TransportControlsView` в `PlayerViews.swift` - UI кнопок управления (backward.end.fill, pause.fill/play.fill, forward.end.fill)
- `AudioPlaybackService.currentTime` и `.duration` обновляются таймером каждые 0.5 секунды
- `formatted(seconds:)` функция форматирования времени

## Архитектура решения

### Новые файлы

```
ATPlayer/
├── LiveActivity/
│   ├── ATPlayerActivityAttributes.swift   // ActivityAttributes модель
│   └── ATPlayerActivityService.swift      // Сервис управления LiveActivity
│
ATPlayerWidgetExtension/                   // Новый Widget Extension target
├── ATPlayerWidgetExtension.swift          // Точка входа виджета
├── ATPlayerLiveActivityView.swift         // UI для Lock Screen и Dynamic Island
└── Info.plist
```

### 1. ATPlayerActivityAttributes (общий для app и extension)

```swift
struct ATPlayerActivityAttributes: ActivityAttributes {
    // Статические данные (не меняются в рамках одного трека)
    struct ContentState: Codable, Hashable {
        let trackTitle: String
        let artistName: String
        let duration: TimeInterval
        let currentTime: TimeInterval
        let isPlaying: Bool
    }
}
```

**Важно:** `ContentState` содержит `currentTime` и `isPlaying`, т.к. они обновляются при каждом update.

### 2. ATPlayerActivityService

Сервис-обёртка над ActivityKit API:
- `startActivity(track:duration:)` - запускает LiveActivity при начале воспроизведения
- `updateActivity(currentTime:isPlaying:)` - обновляет состояние
- `endActivity()` - завершает при остановке

### 3. Widget Extension (ATPlayerWidgetExtension)

UI-компоненты для трёх контекстов:
- **Lock Screen (expanded):** название трека, прогресс-бар, время, кнопки управления
- **Dynamic Island (compact):** иконка + сокращённое название
- **Dynamic Island (expanded):** название, время, кнопки

### 4. Обработка нажатий кнопок

Кнопки в LiveActivity не могут напрямую вызывать код приложения. Варианты:
- **Deep Links (рекомендуется):** кнопки используют `Link` с URL-схемой (`atplayer://previous`, `atplayer://toggle`, `atplayer://next`). Приложение обрабатывает через `.onOpenURL`
- Требуется регистрация URL-схемы `atplayer` в Info.plist

## План работ

### Этап 1: Подготовка инфраструктуры
1. Зарегистрировать URL-схему `atplayer` в Info.plist основного приложения
2. Добавить `NSSupportsLiveActivities = YES` в Info.plist основного приложения
3. Создать Widget Extension target `ATPlayerWidgetExtension` в Xcode (ручное действие)

### Этап 2: Shared модель
4. Создать `ATPlayerActivityAttributes.swift` - положить в общую группу, доступную обоим targets

### Этап 3: Widget Extension UI
5. Создать `ATPlayerLiveActivityView.swift` - Lock Screen и Dynamic Island UI
6. Создать `ATPlayerWidgetExtension.swift` - точка входа Widget

### Этап 4: Сервис управления LiveActivity
7. Создать `ATPlayerActivityService.swift` в основном приложении

### Этап 5: Интеграция
8. В `ATPlayerViewModel`:
   - При вызове `play(track:)` - вызывать `startActivity`
   - Подписаться на изменения `currentTime`/`isPlaying` - вызывать `updateActivity` (с throttle, не чаще раза в секунду)
   - При `stop()` - вызывать `endActivity`
9. В `ATPlayerApp.swift`:
   - Добавить `.onOpenURL` обработчик для deep links
   - Пробросить команды управления в `ATPlayerViewModel`

### Этап 6: Тестирование
10. Проверить запуск/обновление/завершение Activity
11. Проверить работу кнопок на Lock Screen
12. Проверить Dynamic Island (compact и expanded)
13. Проверить корректность обновления времени

## Ограничения и нюансы

- **Частота обновлений:** Apple рекомендует не обновлять LiveActivity чаще 1 раза в секунду. Текущий таймер прогресса (0.5 сек) нужно будет throttle до 1 сек для обновлений Activity
- **Размер ContentState:** ограничен 4 КБ. Artwork (обложка) не влезет - для Lock Screen используем только текст и SF Symbols
- **Widget Extension не имеет доступа** к `AudioPlaybackService` и `ATPlayerViewModel` - вся коммуникация через ActivityKit state updates
- **Создание Widget Extension target** требует ручного действия в Xcode (File > New > Target > Widget Extension). Это нельзя автоматизировать через код
